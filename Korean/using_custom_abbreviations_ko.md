## 사용자 정의 약어 사용법

ROS-e의 약어는 AutoHotkey 스크립트에서 직접 사용자 정의할 수 있습니다.

### 약어 정의 부분 찾기

1.  `ros-e.ahk`를 텍스트 편집기, 메모장 또는 IDE에서 엽니다.

2.  편집기의 검색 기능을 사용하여 다음을 찾습니다.

    ``` text
    GetAbbreviationMap
    ```

3.  `GetAbbreviationMap()` 내부에서 약어 정의 부분을 찾습니다. 다음과 같은 형태입니다.

    ``` ahk
    map["a+x+k"] := "return"
    ```

### 약어 추가 또는 변경

각 약어는 다음 형식을 사용합니다.

``` ahk
map["key+key+key"] := "output text"
```

예:

``` ahk
map["a+x+k"] := "return"
map["a+x+l"] := "function"
map["f+j"] := "example"
```

따옴표 안의 글쇠는 해당 글쇠가 ROS-e에서 일반적으로 출력하는 글자가 아니라, **동시에 누르는 물리 글쇠**를 나타냅니다.

다음과 같이 수정할 수 있습니다.

-   기존 약어의 출력 텍스트 변경
-   기본 약어 교체
-   약어 삭제
-   임의의 물리 글쇠 동시입력 조합을 사용한 새 약어 추가

물리 글쇠를 적는 순서는 상관없습니다. ROS-e는 일치 여부를 확인하기 전에 동시입력 조합을 자동으로 정규화(canonicalize)합니다.

예를 들어 다음 정의들은 모두 동일한 물리 글쇠 동시입력 조합을 나타냅니다.

``` ahk
map["a+x+k"] := "return"
map["k+a+x"] := "return"
map["x+k+a"] := "return"
```

따라서 해당 동시입력 조합에는 하나의 정의만 있으면 됩니다.

### 변경 사항 적용

약어 맵을 편집한 뒤 다음과 같이 적용합니다.

1.  `ros-e.ahk`를 저장합니다.
2.  ROS-e가 이미 실행 중이라면 기존 스크립트를 종료하거나 다시 불러옵니다.
3.  `ros-e.ahk`를 다시 실행합니다.

이제 수정한 약어 세트가 사용됩니다.

> **주의:** 물리 글쇠 동시입력 조합을 약어로 지정하면 해당 조합의 일반적인 ROS-e 출력이 덮어써집니다.
> 따라서 일반적인 영어 철자 입력에 필요할 가능성이 낮은 조합을 선택하는 것을 권장합니다.
